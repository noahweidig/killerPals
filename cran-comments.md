## Notes on content

The package contains colour values derived from the Queen studio album covers.
The album artwork itself is **not** included in the package: it is downloaded
locally by a script under `data-raw/` (which is excluded from the build via
`.Rbuildignore`) and read only as input to the colour derivation. What the
package ships is numeric colour data and graphics generated by the package
itself.

The package name and palette names reference album titles descriptively. The
package is an unofficial tribute and states in its DESCRIPTION, README and
documentation that it is not affiliated with or endorsed by Queen or their
rights holders. No trademarked logo or artwork is reproduced.
